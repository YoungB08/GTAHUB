Developer Onboarding

Tài liệu này dành cho dev mới vào project GTAHUB, một open.mp/SA-MP Pawn gamemode theo kiểu Cảnh Sát và Tội Phạm tại Los Santos. Nội dung tập trung vào cách chạy project, kiến trúc include, các hệ thống runtime, database, command và những điểm dễ nhầm khi sửa code.

Mục tiêu tài liệu

File này là tài liệu nội bộ để đọc nhanh trước khi đụng code. README vẫn là nơi hướng dẫn build/run cơ bản, còn tài liệu này giải thích gamemode được chia module như thế nào và module nào thật sự đang chạy.

Phạm vi rà soát: cây include bắt đầu từ gamemodes/main.pwn, các file gamemodes/core/**/*.inc, scriptfiles, config.json và pawn.json.

Quick start

Yêu cầu

  • open.mp server runtime.
  • Pawn compiler 3.10.11.
  • MySQL server và database, ví dụ gtaopen.
  • sampctl để ensure dependencies và build.

Build

sampctl ensure
sampctl build

Nếu build thành công, output chính là gamemodes/main.amx.

MySQL

Tạo file mysql.ini ở root project, cùng cấp với config.json.

hostname=localhost
username=root
password=yourpassword
database=gtaopen

Nếu MySQL không có password, bỏ hẳn dòng password=. File này đã được ignore và không nên commit.

Run

./omp-server

Server mặc định chạy port 7777, max players 50, script chính là main.

Runtime flow

  1. main.pwn include constants, thư viện, init, utils và toàn bộ core modules.
  2. OnGameModeInit set hostname, gamemode text, language, world time/weather, tắt stunt bonus, bật ped anims.
  3. init.inc đọc mysql.ini, connect MySQL, bật AUTO_RECONNECT.
  4. Nếu SETUP_TABLE là true, hệ thống gọi setup table trước khi chạy logic sau connect.
  5. Server load entrances, ATMs, static vehicles, messages, mapping, dealership, moneybag và các gameplay systems.
  6. Khi player vào server, account flow check ban, login/register, load stats/items/bank/weapons/house/vehicle/admin/VIP.
  7. Per-player tick và server tick xử lý autosave, UI, cooldown, wanted colors, GPS, side jobs và gameplay timers.

Dev workflow

Thêm một gameplay system mới

  1. Tạo file trong gamemodes/core/systems hoặc subfolder phù hợp.
  2. Đặt prefix function theo tên module, ví dụ Fishing_Start, Fishing_Stop.
  3. Include file mới trong core/systems/system.inc hoặc aggregator tương ứng.
  4. Nếu cần DB, thêm setup table module hoặc SQL file, rồi hook vào tables.inc nếu phù hợp.
  5. Hook callback bằng pattern đang dùng trong repo, tránh tạo global trùng tên.
  6. Thêm command qua CMD:, alias qua ALTCMD:, admin command qua ACMD:.
  7. Build lại bằng sampctl build và chạy server với crashdetect.

Sửa module có DB

  • Kiểm tra schema trong scriptfiles/*.sql và setup table trong module.
  • Không đổi tên column nếu chưa có migration hoặc reset DB dev.
  • Với query dài, giữ style multiline static const như README hướng dẫn.
  • Luôn kiểm tra load/save ở cả login, disconnect, autosave và command admin nếu có.

Sửa command

  • Tìm command bằng rg "CMD:command" hoặc rg "ACMD:command".
  • Kiểm tra alias trong ALTCMD:.
  • Cập nhật help text nếu behavior hoặc command name thay đổi.
  • Kiểm tra command cooldown/spam logic trong command framework.

Checklist trước khi merge

Gameplay change

  • Build qua sampctl build.
  • Test command happy path và error path.
  • Test disconnect/reconnect nếu state cần persist.
  • Test khi player chết, bị jail, đổi class/job, vào/ra vehicle nếu liên quan.
  • Kiểm tra wanted level, money, XP, inventory không bị desync.

Database change

  • Schema mới có default hợp lý.
  • Query load/save dùng đúng u_id.
  • Không tạo table trùng với SQL import hiện có.
  • Ghi chú migration hoặc cách reset DB dev.

UI/TextDraw change

  • Destroy TextDraw/PlayerTextDraw khi không dùng.
  • Không để timer/UI state leak sau disconnect.
  • Test nhiều resolution nếu có layout phức tạp.

Gotchas

  • SETUP_TABLE đang là true. README khuyên chạy setup xong thì đổi về false và recompile.
  • Không phải file nào trong core cũng chạy. Luôn đi từ include tree thay vì đoán theo tên file.
  • gps_system.inc đang chạy và phụ thuộc GPS plugin.
  • Static vehicles nằm trong scriptfiles/vehicles/ls.txt, không hardcode toàn bộ trong Pawn.
  • Command help có thể lệch với command thật, cụ thể là XomoX weapon inventory commands.
  • Admin command list trong UI/help không nhất thiết bao phủ mọi ACMD; nên grep code khi audit quyền.
  • Lotto hiện hardcode số trúng là 10, không random như intent nhìn qua tên biến.
  • Army heal label và giá trong code có thể lệch: label nói 500 nhưng logic kiểm tra/trừ 250.
